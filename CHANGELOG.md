# Changelog

All notable project changes are tracked here. Version numbers represent development milestones, not necessarily published GitHub releases.

## [0.3.1-alpha] - 2026-11-14

### Added
- Profile dropdown accessible from the dashboard avatar.
- Profile photo upload (JPG, PNG and WebP, up to 2 MB).
- Persistence of the avatar path in the users table.
- Logout option integrated into the profile menu.

### Fixed
- Avatar upload POST route returning HTTP 405.
- Profile dropdown stacking above dashboard widgets.
- Duplicate logout controls and visual alignment of the header.

## [0.3.0-alpha] - 2026-11-14

### Added
- User registration, login and logout with PHP sessions.
- Password hashing, PDO prepared statements and server-side validation.
- CSRF protection and private-route access checks.
- Dedicated authentication pages following the DevTrack visual identity.

## [0.2.1-alpha] - 2026-11-14

### Added
- Public landing page and responsive navigation.
- Features, demo preview, workflow explanation and calls to action.
- Landing-specific technical documentation.

## [0.2.0-alpha] - 2026-11-13

### Added
- Dashboard interface with illustrative Kanban and study area.
- Light/dark theme selection and glassmorphism styling.

## [0.1.0] - Initial setup

### Added
- Initial PHP project structure and local development setup.
